위치가 안 잡힐 때, PC·휴대폰에서 위치 켜는 법

2026년 10월 6일 · 오땡뭐! 작성

오땡뭐!는 지금 있는 곳에서 걸어갈 수 있는 가게를 고르기 위해 위치를 써요. 위치를 못 가져오면 엉뚱한 동네 가게가 나올 수 있어요. 아래 순서대로 확인해 보세요.

가장 쉬운 방법: 동네 이름 입력

설정을 바꾸기 번거롭다면, 첫 화면 위쪽 칸에 동네나 역 이름(예: 신림역, 홍대입구역, 판교동)을 쓰고 이 근처로를 누르세요. 그 근처 가게로 바로 추천해 드려요. 이미 추천을 받는 중이라면 화면 아래 위치 바꾸기를 누르면 같은 칸이 나와요.

위치를 못 받으면 어떻게 되나요

  • 먼저 인터넷 접속 위치로 대략 어느 구인지 짐작해서 추천해요. 화면 아래에 "인터넷 접속 위치(OO구) 기준"이라고 나와요. 통신사 사정에 따라 실제와 다른 구가 나올 수 있어요.
  • 그것도 알 수 없으면 강남역 기준으로 추천해요.
  • 어느 경우든 동네 이름을 넣으면 그 위치로 바뀌어요.

PC에서 위치가 안 잡힐 때

데스크톱 PC에는 GPS가 없어서, 운영체제의 위치 서비스가 켜져 있어야 브라우저가 위치를 알 수 있어요. 랜선으로만 인터넷을 쓰는 PC는 위치를 아예 못 찾는 경우가 많아요. 이럴 땐 동네 이름 입력이 가장 정확해요.

Windows 10·11

  1. 설정 → 개인 정보 및 보안(Windows 10은 개인 정보) → 위치로 가요.
  2. 위치 서비스를 켜요.
  3. 아래의 앱이 위치에 액세스하도록 허용과 데스크톱 앱이 위치에 액세스하도록 허용을 켜요.
  4. 브라우저를 완전히 껐다가 다시 열어요.

맥(macOS)

  1. 시스템 설정 → 개인정보 보호 및 보안 → 위치 서비스로 가요.
  2. 위치 서비스를 켜고, 목록에서 쓰는 브라우저(Chrome, Safari 등)를 켜요.

브라우저에서 위치 허용하기

크롬·엣지·네이버 웨일

  1. odaengmwo.com 주소창 왼쪽의 아이콘(자물쇠나 조절 모양)을 눌러요.
  2. 위치를 허용으로 바꿔요. 안 보이면 사이트 설정에 들어가서 바꿔요.
  3. 페이지를 새로고침하고 다시 시도를 눌러요.

사파리(맥): 메뉴 막대의 Safari → 설정 → 웹 사이트 → 위치에서 odaengmwo.com을 허용으로 바꿔요.

휴대폰에서 위치가 안 잡힐 때

아이폰

  1. 설정 → 개인정보 보호 및 보안 → 위치 서비스를 켜요.
  2. 같은 화면에서 Safari 웹 사이트(크롬을 쓰면 Chrome)를 눌러 앱을 사용하는 동안으로 바꿔요.
  3. 사파리 주소창의 가가(또는 aA) 버튼 → 웹 사이트 설정 → 위치를 허용으로 바꾸고 새로고침해요.

안드로이드(갤럭시 등)

  1. 화면 위에서 아래로 내려 빠른 설정의 위치를 켜요.
  2. 크롬이나 삼성 인터넷 주소창 왼쪽 아이콘 → 권한(또는 사이트 설정) → 위치를 허용으로 바꿔요.
  3. 새로고침하고 다시 시도를 눌러요.

위치 정보는 어디에 쓰이나요

위치는 근처 가게를 찾을 때만 쓰고, 오땡뭐! 서버에 저장하지 않아요. 가게 검색은 카카오 로컬 검색으로 하고, 길찾기는 카카오맵으로 연결돼요. 자세한 내용은 개인정보처리방침에 있어요.
